BeamCraft Minecraft instance

This portable Prism Launcher instance uses Minecraft 1.21.1 and Fabric Loader 0.19.5.
It includes BeamCraft and Fabric API. Prism downloads Minecraft and Java from their
official providers after you sign in with a Microsoft account that owns Minecraft: Java
Edition. No Minecraft game files are included.

Run install-beamcraft.ps1 once to copy the instance and BeamNG extension into a separate
BeamCraft profile and open Prism for Microsoft sign-in. After signing in, run
play-beamcraft.ps1 to start BeamNG and the modded Minecraft instance together.

No BeamNG game assets are included. BeamCraft reads them from your installed BeamNG game.
