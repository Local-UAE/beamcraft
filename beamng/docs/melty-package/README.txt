BeamCraft for Melty

Requirements
- A Windows PC with Steam and BeamNG.drive installed.
- A Microsoft account that owns Minecraft: Java Edition.
- Internet access for the first Prism launch. Prism downloads Minecraft, Fabric Loader,
  and the Java runtime from their official providers after you sign in.

First setup
1. Run install-beamcraft.bat.
2. In Prism Launcher, sign in with the Microsoft account that owns Minecraft: Java Edition.
   Close Prism after the account has been added.

Play
- Run play-beamcraft.bat. It starts BeamNG.drive and the BeamCraft Minecraft instance.
- In Minecraft, walk to the car and right-click with an empty hand to drive.

BeamCraft runs the BeamNG and Minecraft games together on one PC for one player. It does not
include either game's files or assets. The BeamNG car data is read from your own BeamNG install.
No shared/network play is supported.
